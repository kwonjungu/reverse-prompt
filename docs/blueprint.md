# **App Name**: PromptGrader

## Core Features:

- Image Display: Display an image for which the user needs to create a descriptive prompt.
- Prompt Input: Input field for students to enter their descriptive prompt.
- Prompt Evaluation: AI tool that evaluates the student's prompt based on a rubric.
- Improvement Suggestions: Generative AI provides specific suggestions for improving the prompt based on the rubric's criteria. It uses reasoning to decide when or if to incorporate details from the sample prompt.
- Score Display: Display the evaluation results (score and feedback) to the student.
- Next Question: Button to load a new image and reset the prompt input field for the next question.

## Style Guidelines:

- Primary color: Soft blue (#89B4FA) to evoke a sense of calm and focus suitable for educational settings.
- Background color: Very light blue (#F0F8FF), nearly white to reduce distractions and allow images to stand out.
- Accent color: Muted purple (#B694F7) for interactive elements (buttons, links) to guide user attention without overwhelming.
- Body and headline font: 'Inter', sans-serif, for a clean, modern, readable appearance appropriate to an educational app.
- Simple, line-based icons for navigation and interactive elements.
- Clean and spacious layout to ensure clarity and focus on the image and prompt input field.
- Subtle transitions when loading new images or displaying feedback.
